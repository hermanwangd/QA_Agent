# Documentation Index

This folder is organized by responsibility.

## Strategy

`strategy/` contains the high-level proposal and reasoning for why the QA Control Layer must exist before AI Coding is scaled.

## Architecture

`architecture/` contains the operating model: role boundaries, artifact lifecycle, approval gates, and control rules.

## Contracts

`contracts/` contains machine-readable starting points for framework and agent integration:

- Product / RP release testing input
- Framework dry-run readiness report
- Human approval record

These files are intentionally versioned with `v0.1` because they should evolve through implementation feedback.

## Roadmap

`roadmap/` contains staged implementation plans and definitions of done.
